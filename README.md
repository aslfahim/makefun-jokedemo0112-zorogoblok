Entry for the make.fun bounty [The joke about the demo](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112).

`main.ts` (Node 22) writes one one-line joke about working beside AI coding
agents to `/output/entry.txt`. The joke is written in this session, on the
angle of confident wrongness: an agent supremely, unshakeably certain about
something that is visibly, demonstrably false.

## Run

```sh
node main.ts
cat /output/entry.txt
```
